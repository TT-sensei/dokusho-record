# 読書レコード

読んだ本を、自分の本棚に一冊ずつ積み重ねていく読書記録アプリです。

冊数を競うのではなく、表紙や背表紙を眺めながら「これだけ読んだ」という自分の歩みを振り返れることを大切にしています。タブレットでの利用を中心に、子どもにも扱いやすい画面を目指しています。

**公開ページ：** https://tt-sensei.github.io/dokusho-record/

## できること

- **本棚**：登録した本を表紙または背表紙で表示
- **検索・絞り込み**：タイトル・著者・ISBNで検索し、お気に入り、今月、今年の本に絞り込み
- **本の登録**：ISBNを入力するか、カメラでバーコードを読み取って書誌情報を検索
- **表紙の登録**：ISBN検索で取得した表紙を使うほか、カメラで撮影したり端末の写真を選んだりできる
- **読書の記録**：読了日、ひとこと感想、読後の気持ちを記録
- **お気に入り**：あとから読み返したい本をマーク
- **読書目標**：月間・年間の目標を設定し、読書の積み重ねを振り返る
- **バッジ**：読書冊数や取り組みの節目を記録
- **バックアップ・復元**：本棚データをJSON形式で保存。必要に応じて撮影した表紙画像も含められる

## 使い方

1. 公開ページを開きます。
2. 「本を登録」から、ISBNで探す・表紙を撮る・写真から選ぶ、のいずれかを選びます。
3. ISBN検索では、バーコードを読み取るかISBNを入力します。情報が見つからない場合は、手入力でも登録できます。
4. 登録した本は「本棚」に並びます。本を開くと、感想の記録、お気に入り設定、表紙の追加・変更、編集や削除ができます。
5. 「設定」から読書目標やバックアップを管理できます。

## データの保存とプライバシー

読書レコードは、ログインやアカウント登録を必要としません。読書記録は利用しているブラウザ・端末内に保存され、アプリ独自のサーバーへ送信する仕組みはありません。

- 本の情報や設定：ブラウザの `localStorage`
- カメラや端末から登録した表紙画像：ブラウザの `IndexedDB`
- ISBN検索で取得した表紙：画像ファイルを端末に複製せず、表紙URLを保存

**大切な注意：** ブラウザのデータを消去したり、別の端末・ブラウザに移行したりすると、記録が失われる場合があります。定期的にJSONバックアップを保存してください。撮影・選択した表紙も引き継ぎたい場合は、バックアップ時に画像を含める設定を選んでください。画像を含めたバックアップはファイルサイズが大きくなります。

ISBN検索では外部の書誌情報サービスに問い合わせます。検索にはインターネット接続が必要です。外部サービスの提供状況や登録情報によっては、情報や表紙が見つからないことがあります。

## オフライン利用・ホーム画面への追加

アプリはService Workerでアプリ本体のファイルをキャッシュするため、一度読み込んだ後は、対応するブラウザで本棚や保存済みの記録を利用できます。ISBN検索など、外部サービスへの接続が必要な機能はオフラインでは利用できません。バーコード読み取りには対応ブラウザ、カメラへのアクセス許可、必要な接続環境が必要です。

対応端末では、ブラウザの共有メニューなどからホーム画面に追加すると、アプリのように起動できます。

## 技術構成

- HTML / CSS / JavaScriptによる静的Webアプリ
- GitHub Pagesで公開
- `localStorage`：読書記録・設定の保存
- `IndexedDB`：ユーザーが追加した表紙画像の保存
- Service Worker / Web App Manifest：キャッシュとホーム画面追加への対応
- QuaggaJS：ISBNバーコードの読み取り
- ISBN書誌情報：Google Books、openBD、国立国会図書館サーチ（NDLサーチ）を利用

ビルド工程や独自のバックエンドはありません。公開ページを開いて利用できます。

## 開発・確認について

画面や保存処理を変更した場合は、少なくとも次の流れを確認してください。

- 本の登録、検索、編集、削除
- お気に入りと読後の気持ちの保存
- 表紙表示・背表紙表示の切り替え
- 月間・年間目標の変更
- JSONバックアップの書き出しと復元
- 撮影・選択した表紙画像を含めたバックアップと復元
- オフライン時の本棚表示と、再接続後のISBN検索
- タブレット・スマートフォンでの表示と操作

カメラ、バーコード読み取り、IndexedDB、Service Workerの挙動は、実際の対応端末・ブラウザでも確認してください。
